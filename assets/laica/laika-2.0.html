Laika 2.0

Mascota en caricatura inspirada en Laika, la perrita espacial. Parpadea, respira y te sigue con la mirada. Toca un gesto o haz clic sobre ella.

Usarla en tu proyecto

  1. Abre este archivo y copia los tres bloques marcados con LAIKA: SVG, CSS y JS.
  2. Pégalos en tu página.
  3. Lanza los gestos desde tu código:
Laika.play('saludar');   // al iniciar
Laika.play('celebrar');  // al ganar
Laika.play('triste');    // al perder
Laika.stop();            // volver al reposo

// Gestos: saludar, saltar, celebrar,
// triste, ladrar, ladear, cola

// Avisa cuando termina un gesto:
document.addEventListener('laika:fin',
  e => console.log(e.detail.gesto));
